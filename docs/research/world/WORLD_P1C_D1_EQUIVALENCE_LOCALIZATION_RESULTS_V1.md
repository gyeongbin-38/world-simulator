## 6. Scientific interpretation

The D1 result supports the following bounded interpretation:

1. The P1C G0 failure is not evidence that the Foundation-to-Policy phase-ablation hypothesis itself failed. P1C stopped before phase-attribution gates by design because its measurement-equivalence control failed.
2. The P1C discrepancy is exactly reconstructable from the bare BASE full-versus-cached BF16 execution contrast.
3. No PEFT-wrapper contribution was observed under adapter-disabled full or cached scoring in D1.
4. The large BF16 discrepancy includes rank changes and therefore must not be reclassified as an ignorable tolerance issue.
5. FP32 sharply attenuates the discrepancy but does not make the two execution topologies exactly identical.
6. D1 did not test FA-enabled full-versus-cached common-mode behavior; no claim is made that the cached execution artifact is identical under FA-enabled conditions.

The recommended next experiment is a separately preregistered phase-ablation design that compares causal conditions under a common execution topology rather than comparing ordinary full-sequence scoring directly against cached split-prefill scoring.

No P1C threshold is relaxed retroactively. No scalar correction is introduced.
