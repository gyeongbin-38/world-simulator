# 공개 준비 현황

이 문서는 저장소의 소개 자료를 정리한 시점의 상태입니다. 원본 실험 기록, 이용 조건, 외부 자료의 출처를 대신하지 않습니다.

## 정리한 내용

- README에서 개인 연구 프로젝트의 질문과 세 연구 축을 소개합니다.
- [연구 안내](research/README.md)에서 실험 설계·결과·명세를 연결합니다.
- [재현 안내](REPRODUCIBILITY.md)에서 GPU 없는 코드 검증과 실제 모델 실험을 구분합니다.
- 기존 결과·manifest·원시 증거를 수정하지 않고, 실행되지 않은 F0 A/B 계획의 상태를 유지합니다.

## 소개 문서 검증 · 2026-11-27

Python 3.12.13의 별도 개발 환경에서 `uv sync --locked` 설치를 확인했습니다. 문서 lint가 통과했고, README에 안내한 계약·커널·복원 테스트는 **53 passed**였습니다. 이 검증은 과거 LLM 실험의 원시 결과를 재감사한 기록과 구분합니다.

## 공개 배포 전에 확정할 항목

| 항목 | 현재 확인한 상태 | 필요한 정리 |
|---|---|---|
| 코드 license | `pyproject.toml`에 MIT 표기, 저장소 루트에 별도 LICENSE 파일 없음 | 권리자·적용 범위를 확인하고 일치하는 license 본문 추가 |
| 연구 문서·데이터 이용 조건 | 별도 조건을 이 정리 작업에서 확인하지 않음 | 코드와 동일한 조건을 적용할지, 별도 조건을 둘지 명시 |
| 외부 모델·라이브러리 | 실험 기록·명세·dependency 파일에 사용 내역이 분산돼 있음 | revision과 출처를 연결하고 재배포 대상의 조건 확인 |
| 원시 증거 | 결과 문서가 로컬 보관 경로와 hash를 참조함 | 공개 가능한 run을 골라 manifest와 감사 명령을 포함한 배포 패키지 구성 |
| hidden/reserved 평가 자료 | 격리된 평가 관련 명세가 존재함 | 공개 증거와 분리하고 각 명세의 공개 제한 확인 |
| 기여 표시 | 코드·문서의 작업 이력이 Git에 있음 | 연구 책임, 외부 자료, AI 보조 범위를 사실에 맞게 기재 |

이 상태표는 전체 Git 이력에 대한 비밀정보·권리 검토가 완료됐다는 의미가 아닙니다. 비공개 저장소를 공개로 전환하는 작업은 이번 문서 정리에 포함하지 않습니다.

## 기여와 AI 보조 작업

이 프로젝트는 개인 연구 프로젝트로 소개합니다. 외부 모델과 라이브러리는 해당 제공자의 작업이며, 이를 사용한 실험 설계와 구현, 분석은 각 연구 기록 및 Git 이력을 통해 확인합니다.

이번 소개 문서 정리에는 AI 코딩 도구가 사용됐습니다. 기존 코드·설계·분석 전체의 AI 사용 범위는 이번 작업만으로 확정할 수 없으므로, 과거 기여를 일괄적으로 선언하지 않습니다. 연구 책임자와 AI 보조 작업의 구체적인 범위는 확인 가능한 기록을 바탕으로 추가해야 합니다.

## 인용

현재 이 정리 작업에서 논문 출판 정보나 DOI는 확인하지 않았습니다. 저장소를 언급할 때는 프로젝트 이름 **A-LifeLM / World Simulator**, 저장소 URL, 사용한 branch 또는 tag와 commit을 함께 남기면 검토한 자료의 버전을 구분할 수 있습니다. 특정 연구 주장은 해당 실험 명세와 결과 문서까지 연결하세요.
